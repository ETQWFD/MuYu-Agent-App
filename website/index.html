安装说明

1. 允许安装未知来源

下载完成后，点击安装包。若系统提示"禁止安装未知应用"，在设置中为浏览器或文件管理器打开"允许安装应用"。

2. 覆盖安装

如果之前装过其它签名的旧版本，需要先卸载旧版再安装，否则会提示"应用未安装"。

3. 首次启动

首次打开会引导你选择本地模型或填入云端 API。没有本地模型时，直接用云端 API 也能对话。

4. 应用内更新

设置 → 关于 → 检查更新，会从本仓库的 Release 拉取新版本并直接安装。
