开始使用

第一次打开，怎么开始对话？

两种方式任选其一：

  1. 云端 API：在设置里填入服务商地址、模型名和 API Key，保存后即可对话。适合所有机型，32 位手机也完全可用。
  2. 本地模型：下载一个 GGUF 模型放入模型库，选择后在本机推理，对话内容不出设备。需要 64 位设备与足够的运行内存。
在哪里配置 API Key？

进入「设置 → 模型 / API」填写 Base URL、模型名与密钥。密钥只保存在本机应用私有目录，不会上传到任何第三方服务器。

下载的模型放在哪里？

应用内「模型管理 → 导入模型」即可，支持从本地文件导入或从推荐列表下载。模型文件较大，建议在 Wi-Fi 下操作。

32 位手机说明

32 位（armeabi-v7a）能做什么？

安装包同时提供 64 位和 32 位库，32 位手机会自动使用 32 位版本。界面、会话、云端 API 对话、设置、模型管理均可正常使用，不会因为缺少库而闪退。

厂商 NPU 推理库（高通 QNN / 联发科 Neuron / MNN 图像模型）只提供 64 位二进制，因此 32 位设备上这些本地加速项不可用。应用会在「关于」页标注当前运行 ABI 与不可用能力，而不是直接崩溃。
怎么确认自己手机是 32 位还是 64 位？

打开「设置 → 关于」，页面顶部会显示运行 ABI，例如 arm64-v8a · 64 位 或 armeabi-v7a · 32 位。

安装与更新问题

提示"应用未安装"或"签名不一致"

说明手机上已有一个不同签名的同包名应用。先卸载旧版（卸载会清除应用内数据，重要会话请先导出），再安装新版。

检查更新一直转圈或失败

应用会优先直连 GitHub，再自动回退到国内加速镜像。若网络受限，可先在官网页面手动下载最新安装包覆盖安装。

更新后数据还在吗？

在未卸载的前提下覆盖安装，会话与设置都保留；卸载重装会清空应用数据。

反馈

遇到问题怎么反馈？

请在 GitHub Issues 提交，附上机型、系统版本、「关于」页显示的 ABI 与版本号，以及复现步骤。

这个项目和上游是什么关系？

MuYu-Agent 基于上游 MuYu Chat Agent（作者 lyydfys）二次开发，保留 Apache-2.0 许可与原作者署名，主要改动为品牌、图标、32 位兼容与更新源。
